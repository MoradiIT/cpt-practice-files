# Cisco Packet Tracer Practice Files

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

This repository contains files and templates that can be used with **Cisco Packet Tracer (CPT)** to make network simulation and practice easier.

The repository currently includes:

* **Sample websites for web server practice**
* **Device icons** for use in network topologies (EVE-NG Icons)
* **Pre-configured device templates** with commonly used settings, ready to use in simulations

More practice files and templates may be added over time.
